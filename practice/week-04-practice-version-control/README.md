# Practice: Version Control

## Task Brief
Create a feature branch, make code improvements to your data pipeline, and submit a pull request with clear description and commit messages. Continue building on your prior submission.

## Scenario
Your data team needs you to add a new data validation function to the pipeline. Create a feature branch, implement the function, and submit a pull request for team review.

## Deliverables
- Feature branch with validation function
- Pull request with clear description
- Updated data pipeline module

## Success Criteria
- Pull Requests: Feature branch created with descriptive name
- Pull Requests: Pull request opened with clear title and description
- Pull Requests: Commit messages follow best practices
- Pull Requests: Code changes reviewed and ready to merge
