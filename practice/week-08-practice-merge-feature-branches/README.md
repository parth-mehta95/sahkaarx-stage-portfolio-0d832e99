# Practice: Merge Feature Branches

## Task Brief
Merge multiple feature branches into main using appropriate merge strategies; maintain clean commit history.

## Scenario
Your team completed multiple features on separate branches. Merge them into main using appropriate strategies while keeping history clean.

## Deliverables
- Multiple merged feature branches in main
- Clean commit history showing merge decisions
- Merge strategy documentation

## Success Criteria
- Merging: Successfully merge feature branches using fast-forward, three-way, and squash strategies
- Merging: Maintain clean, readable commit history after merges
- Merging: Document merge strategy decisions in repository
