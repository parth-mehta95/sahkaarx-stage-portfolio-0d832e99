# Practice: Resolve Merge Conflicts

## Task Brief
Intentionally create and resolve merge conflicts in your data pipeline repository to practice conflict resolution and collaborative Git workflows.

## Scenario
Your team made concurrent changes to the data pipeline. Create a merge conflict, resolve it using best practices, and merge cleanly.

## Deliverables
- Resolved merge conflict in GitHub repo
- Clean commit history showing resolution
- Updated pipeline code

## Success Criteria
- Conflict Resolution: Successfully identify and resolve merge conflict markers
- Conflict Resolution: Apply appropriate resolution strategy and document rationale
